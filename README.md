# Sanskriti AI

**"Your GenAI Companion for Indian Culture & Tourism"**

A culturally immersive AI-powered platform that blends education, tourism, and storytelling to help users explore India's vast heritage through interactive, personalized experiences.

---

## 🌍 Overview

**Sanskriti AI** is a Generative AI web app developed by **Team Codestars** to address the gap between India’s rich cultural resources and the modern digital experience. It serves as an intelligent guide for both tourists and learners, offering real-time assistance in multiple languages through a conversational AI embedded in a 3D environment.

---

## 🧠 Key Features

### 🕹️ 3D Unity Experience
- Explore Indian culture in a gamified 3D environment.
- Voice-activated conversations with an AI character.
- EdTech + Tourism synergy in an immersive format.

### 🤖 Intelligent Q&A System
- Context-aware answers about Indian heritage, monuments, traditions.
- Sources and references included.
- Multilingual voice-to-text translation (English, Hindi, Kannada).

### 📅 Personalized Travel Planner
- Day-wise itinerary with:
  - Activity scheduling (morning/afternoon/evening)
  - Local food recommendations
  - Travel time estimates
- Automatically generates metadata for each location/activity.

### 🧩 Interactive Quiz Module
- Adaptive quiz difficulty (easy/medium/hard).
- Topic-specific quizzes (e.g., festivals, dance forms).
- AI-powered semantic hints that don’t spoil answers.

### 📖 Dynamic Storytelling Engine
- Generates region-specific folktales and mythological stories.
- Customizable length and detail.
- Text-to-speech audio with native language output.
